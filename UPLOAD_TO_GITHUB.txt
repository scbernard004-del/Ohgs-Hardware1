OHGS WEBSITE — SIMPLE GITHUB UPLOAD

This package is ready to upload directly to the ROOT of your GitHub repository.

1. Extract OHGS_GITHUB_UPLOAD_READY.zip on your phone or computer.
2. In the GitHub repository, choose Add file > Upload files.
3. The easiest method is GitHub Desktop: clone the repository, copy ALL extracted files into its folder, then Commit and Push.
   If you use the GitHub website, upload no more than 100 files per batch. Upload root files and api first, then media, then the files inside media/responsive in batches. Keep the same folder names.
4. Do not upload the ZIP itself or the outer extracted folder.
5. Check that index.html is visible at the repository root, beside products.html.
6. Commit the files with a message such as: Deploy OHGS v41 automatic video playback.
